# Slitaz-Project-on-old-PC (Start Page)

-----------------------11-8-2026-----------------------

This is the start of the project, where I first repurposed the old PC into a Slitaz computer.  The end goal is to create a lightweight programming PC for me to study linux in a general sense and to eventually learn networking, including communicating with other PCs in my home network.

Basic Specs of the PC:
-Intel Pentium G645 dual-core processor 
-4 GB of RAM
-Originally ran Windows 8
-500 GB HDD Storage
